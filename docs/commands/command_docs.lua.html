--- Client Commands -- @topic Commands -- This page documents all the commands available in the Runes MUD client. -- All commands start with a forward slash (/). -- Type /help in the client to see a list of available commands.

--- Connect to a MUD server -- @command /connect -- Connects to a MUD server at the specified host and port. -- @param host The hostname or IP address of the MUD server -- @param port The port number of the MUD server -- @usage /connect example.com 4000 -- @usage /connect localhost 4000

--- Disconnect from the current server -- @command /disconnect -- Disconnects from the current MUD server. -- @usage /disconnect

--- Quit the client -- @command /quit -- Exits the Runes MUD client. -- @usage /quit

--- Buffer management commands -- @command /buffer > -- Provides commands for managing buffers. -- @param action Either "list" to show all buffers or "switch" to change to a different buffer -- @param name The name of the buffer to switch to (only needed with "switch") -- @usage /buffer list -- @usage /buffer switch system

--- Show help for all commands or a specific command -- @command /help [command] -- Displays help information for commands. -- @param command Optional command name to get help for -- @usage /help -- @usage /help connect

--- Load a script file -- @command /load -- Loads and executes a Lua script file. -- @param path Path to the Lua script file to load -- @usage /load myscript.lua -- @usage /load /absolute/path/script.lua

--- List all defined aliases -- @command /aliases -- Shows a list of all defined aliases. -- @usage /aliases

--- List all defined triggers -- @command /triggers -- Shows a list of all defined triggers. -- @usage /triggers

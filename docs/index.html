API Reference

runes Core Module This module provides the core functionality for the Runes MUD client, including connection management, input/output handling, and script loading.
trigger Trigger System This module provides functionality for creating and managing triggers that respond to patterns in the MUD output.
alias Alias System This module provides functionality for creating and managing aliases that transform user input before sending it to the server.
events Events System This module provides an event system for registering and handling events throughout the Runes MUD client.
timer Timer System This module provides functionality for creating and managing timers that execute functions at specified intervals.
input Input System This module provides functionality for managing user input and command processing.

Module events

Events System This module provides an event system for registering and handling events throughout the Runes MUD client.

Functions

runes.events.add (eventName, handler) Registers a handler function for a specific event.
runes.events.emit (eventName, eventData) Emits an event, triggering all registered handlers.
runes.events.clear (eventName) Removes all handlers for a specific event.
runes.events.remove (eventName, handler) Removes a specific handler function from an event.
runes.events.list () Lists all events that have registered handlers.


Functions

runes.events.add (eventName, handler)
Registers a handler function for a specific event.

Parameters:

  • eventName string The name of the event to listen for
  • handler function The function to call when the event occurs

Usage:

    runes.events.add("connect", function(data)
    runes.output("Connected to server: " .. data.host)
end)
runes.events.emit (eventName, eventData)
Emits an event, triggering all registered handlers.

Parameters:

  • eventName string The name of the event to emit
  • eventData any Data to pass to the event handlers

Usage:

    runes.events.emit("custom_event", { value = 123 })
runes.events.clear (eventName)
Removes all handlers for a specific event.

Parameters:

  • eventName string The name of the event to clear handlers for

Usage:

    runes.events.clear("custom_event")
runes.events.remove (eventName, handler)
Removes a specific handler function from an event.

Parameters:

  • eventName string The name of the event
  • handler function The handler function to remove

Returns:

    boolean True if the handler was found and removed, false otherwise

Usage:

    runes.events.remove("connect", myConnectHandler)
runes.events.list ()
Lists all events that have registered handlers.

Returns:

    table A list of event names

Usage:

    local events = runes.events.list()
for _, name in ipairs(events) do
    runes.output("Event: " .. name)
end

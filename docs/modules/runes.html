Module runes

Core Module This module provides the core functionality for the Runes MUD client, including connection management, input/output handling, and script loading.

It serves as the main entry point for interacting with the Runes API.

add_output_processor (processor)
Adds a function to process output lines. The processor function receives a line object and should return a line object or nil.

Parameters:

  • processor The processor function

Usage:

    runes.add_output_processor(function(line)
    line:gag(true) -- Hide this line
    return line
end)

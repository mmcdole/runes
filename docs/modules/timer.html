Module timer

Timer System This module provides functionality for creating and managing timers that execute functions at specified intervals.

Functions

runes.timer.add (interval, callback, repeating) Adds a new timer that executes a function at specified intervals.
runes.timer.remove (id) Removes a timer by its ID.

runes.timer.disable (id) Disables a timer without removing it.

Functions

runes.timer.add (interval, callback, repeating)
Adds a new timer that executes a function at specified intervals.

Parameters:

  • interval number Time in milliseconds between executions
  • callback function Function to execute when the timer fires
  • repeating boolean If true, timer will continue executing until removed

Returns:

    number Timer ID that can be used to remove or modify the timer

Usage:

    local timerId = runes.timer.add(1000, function()
    runes.output("One second has passed!")
end, true)
runes.timer.remove (id)
Removes a timer by its ID.

Parameters:

  • id number The ID of the timer to remove

Returns:

    boolean True if the timer was found and removed, false otherwise

Usage:

    runes.timer.remove(timerId)
runes.timer.enable (id)
Enables a timer that was previously disabled.

Parameters:

  • id number The ID of the timer to enable

Returns:

    boolean True if the timer was found and enabled, false otherwise

Usage:

    runes.timer.enable(timerId)
runes.timer.disable (id)
Disables a timer without removing it.

Parameters:

  • id number The ID of the timer to disable

Returns:

    boolean True if the timer was found and disabled, false otherwise

Usage:

    runes.timer.disable(timerId)
runes.timer.list ()
Lists all active timers.

Returns:

    table A list of timer IDs and their properties

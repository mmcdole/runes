Module trigger

runes.trigger.add (name, pattern, options, callback)
Adds a new trigger that responds to a pattern in the MUD output.

Parameters:

  • name string Name of the trigger for reference
  • pattern string Lua pattern to match against incoming text
  • options table|function Optional table of settings or the callback function
  • callback function Function to call when pattern matches (if options provided)

Returns:

    number Unique ID of the created trigger

Usage:

    runes.trigger.add("hp_watch", "HP: (%d+)/(%d+)", function(matches, line)
   if tonumber(matches[1]) < 100 then
       runes.output("Low health warning!")
   end
end)
runes.trigger.remove (id_or_name)
Removes a trigger by its ID or name.

Parameters:

  • id_or_name number|string The ID or name of the trigger to remove

Returns:

    boolean True if the trigger was found and removed, false otherwise

Usage:

  • runes.trigger.remove(5)  -- Remove by ID
  • runes.trigger.remove("hp_watch")  -- Remove by name

runes.trigger.list ()
Lists all triggers.

Returns:

    table Array of trigger information tables

Usage:

    local all_triggers = runes.trigger.list()
for _, t in ipairs(all_triggers) do
    runes.output(string.format("Trigger: %s (ID: %d)", t.name, t.id))
end

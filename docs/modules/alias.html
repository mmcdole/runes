Module alias

Alias System This module provides functionality for creating and managing aliases that transform user input before sending it to the server.

Functions

runes.alias.add (pattern, callback)
Adds a new alias with a regex pattern.

Parameters:

  • pattern string The Lua pattern to match against input
  • callback

    function|string Function or string to execute when matched.

                 If string: sends the string as a command
             If function: called with (matches, input) arguments

Usage:

  • runes.alias.add("^hp$", "look at health")
  • runes.alias.add("^cast (.+) at (.+)$", function(matches, input)
    runes.send("cast " .. matches[1] .. " " .. matches[2])
end)
runes.alias.exact (text, callback)
Creates an alias that matches text exactly.

Parameters:

  • text string The text to match exactly (will be escaped for regex)
  • callback function|string Function or string to execute when matched

Usage:

    runes.alias.exact("hp", "look at health")
runes.alias.any (texts, callback)
Creates an alias that matches any of the provided texts exactly.

Parameters:

  • texts table Array of text strings to match (each will be escaped)
  • callback function|string Function or string to execute when matched

Usage:

    runes.alias.any({"hp", "health", "hitpoints"}, "look at health")
runes.alias.starts (prefix, callback)
Creates an alias that matches text starting with the given prefix.

Parameters:

  • prefix string The prefix to match at the start (will be escaped)
  • callback function|string Function or string to execute when matched

Usage:

    runes.alias.starts("cast ", function(matches, input)
    runes.send("cast_spell " .. matches[1])
end)
runes.alias.resolve (input)
Attempts to match input against registered aliases.

Parameters:

  • input string The input string to check against aliases

Returns:

    function|nil Returns a wrapper function if matched, nil otherwise

Usage:

    local handler = runes.alias.resolve("hp")
 if handler then handler() end
runes.alias.remove (pattern)
Removes an alias by its pattern.

Parameters:

  • pattern string The exact pattern string that was used to create the alias

Usage:

    runes.alias.remove("^hp$")
runes.alias.list ()
Returns a list of all defined aliases.

Returns:

    table A list of alias patterns

Usage:

    local all_aliases = runes.alias.list()
for _, pattern in ipairs(all_aliases) do
    runes.output("Alias pattern: " .. pattern)
end
